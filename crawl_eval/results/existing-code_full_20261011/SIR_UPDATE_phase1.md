# Update for sir – Phase 1: testing the existing crawler (unchanged)

* **What we tested:** the existing crawler, without any change, on 988 URLs: 600 normal websites in 11 types and 388 difficult cases (dead, parked, blocked, slow, broken, bad input, crawl traps). 804 are real sites; each was crawled once (rows that did not match got one extra independent check). Plus extra tests: 60,000-URL import, 1,000-site run, cancel and crash recovery.
* **Overall coverage of the requirements:** 48.0% (weighted), 48.7% for the MUST items. Of 79 applicable MUST requirements 10 fully pass, 57 partly, 10 fail, 2 not tested.
* **What works well:** normal websites (94.5% match); homepage-first and at most 8 pages; junk pages skipped; blocked sites, HTTP errors, TLS errors and "robots disallow all" handled; 19 of 20 crawl traps did not trap it; no failing site stopped the batch; a killed run recovered with nothing lost.
* **Most serious problems:** (1) the browser fallback can be redirected to an internal address and stores what it finds; (2) a decompression bomb can use unlimited memory; (3) the address safety check misses a cloud-metadata range; (4) one bad URL crashes the whole import. All four are Critical.
* **Quality of the data:** it finds only 34% of the important pages (About / Services / Products); the ranking gives score 0 to many real pages, especially non-English ones. On 59 sites it threw away the whole page text because of a CSS class name. The browser fallback reads the page too early and rarely helps.
* **Error-path behaviour:** only 62.0% of the difficult cases are handled as the requirements say. Parked domains are saved as normal results (0 of 30 recognised); placeholder and login pages are saved as normal; a dead domain is called "invalid" instead of "unreachable"; there is no status for Parked, Redirected or Under Construction.
* **Performance and reliability (this run only):** median 7.44 s per site, 95th percentile 55.96 s at concurrency 5; no crash of the crawl; memory small (297 MB peak). 1,000 local sites finished in 91 s. We make **no** claim about 60,000 sites.
* **Two items for your decision:** (a) when a site's robots.txt answers a server error (5xx), the crawler treats it as "allowed"; the standard says "disallowed". We need a written policy. (b) Some sites (11 of 21 blocked ones) refuse the crawler's honest User-Agent; we do not bypass this, as the requirements forbid it.
* **Honest limits:** sites change and the test ran from Lahore (29 rows are marked as network-caused and not counted); the sample favours large, old organisations; one run on one day; Excel upload and the web paste box were not tested.
* **What happens next:** after your approval, Phase 2 builds a new crawler that meets every requirement, then tests it on the same URLs and compares line by line with these results. Nothing in Phase 2 has been started.
